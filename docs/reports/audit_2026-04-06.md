## 🔴 Critical Issues (Yêu Cầu Sửa Chữa Khẩn)

- **Các File Liên Quan:**
  - `lib/openclaw/bot-conversation.ts` (Dòng 268)
  - `lib/openclaw/gamification-commands.ts` (Dòng 97, 189)
  - `lib/openclaw/digest-scheduler.ts` (Hàng loạt dòng 27, 79, 222)
  - `lib/gamification/achievements.ts`

- **Tình Trạng (Triệu Chứng):** Rất nhiều logic về tính điểm (`PointTransaction`), nhận thành tựu (`UserAchievement`), và bắn thông báo (`PushLog`) đang bị comment ẩn đi cùng với ghi chú `// TODO: Restore when pointTransaction table is added`.
- **Hậu Quả:** Do Database vừa hoàn tất nâng cấp 4 bảng mới ở phiên trước mà code chưa kịp phục hồi, tính năng Game hoá & Push đang hoàn toàn tê liệt. Người dùng dùng app sẽ không hề nhận được điểm hay huy hiệu.
- **Cách Chữa Trị:** Gõ lệnh quyét toàn bộ Project tìm chữ `TODO: Restore` và Uncomment (mở lại code) toàn bộ những file tĩnh ở thư mục API và Openclaw.

## 🟡 Warnings (Nên Chăm Sóc Sớm)
### 1. Hardcoded Supabase URL rác rưởi (Dead Secrets)
- **File Liên Quan:** Các bash scripts cũ như `setup-real.sh`, `scripts/update-avatars.mjs`, `test-mock-inject.js`.
- **Triệu Chứng:** Môi trường code vẫn lác đác những nơi chứa biến `NEXT_PUBLIC_SUPABASE_URL` và `SUPABASE_SERVICE_ROLE_KEY`.
- **Đánh Giá Nguy Hiểm:** Rất thấp. Vì mình đã chuyển sang NextAuth & Prisma, nên mấy cái này thực tế chỉ là rác lịch sử. Bọn chúng không được dùng thực tại Client. Tuy nhiên, nó khiến mã nguồn dơ.
- **Cách Chữa Trị:** Xóa bỏ đi hoặc cất hết vào một thư mục Archive.

## 🟢 Đánh Giá Tích Cực (Điểm Cộng Sức Khoẻ)
### 1. Lớp Khiên Authentication
- Middleware Next.js (`middleware.ts`) đang khóa chặt tất cả đường `/api/` với `NextResponse.json({ error: "Unauthorized" }, { status: 401 })`. Ngoại trừ `api/cron` bảo vệ bằng CRON_SECRET và `auth` được miễn.
- **Hoàn toàn AN TOÀN trước rủi ro dò gỉ dữ liệu người lạ qua API.**

### 2. Quản Lý Secrets (.env)
- Việc setup `.env.local` hiện tại không hề bị đẩy lên Github. Biến `NEXTAUTH_SECRET` được bọc gói kĩ thông qua `getAuthUserId` ở Backend, không hề rò rỉ JWT secret cho frontend.
