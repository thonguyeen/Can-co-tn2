# Plan: Floating Chat Widget (Trợ lý Bot Góc Dưới)
Created: 2026-04-02 20:55
Status: 🟡 In Progress

## Overview
Cung cấp khu vực cho User trò chuyện nhắn tin trực tiếp với Trợ lý AI (Bot Envoy) qua khung Chat Bong Bóng (Widget) góc dưới bên phải màn hình. Bot sẽ tư vấn BĐS giống như đang chat Messenger.

## Tech Stack
- Frontend: Next.js Client Component, TailwindCSS, Framer Motion (hiệu ứng nảy bông nhẹ).
- Backend: Next.js API Routes (`/api/chat`).
- AI Core: `openai` qua `lib/ai/client.ts` có sẵn của dự án.
