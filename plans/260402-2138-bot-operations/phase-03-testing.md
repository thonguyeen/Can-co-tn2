## Objective
Kiểm tra toàn bộ luồng: Bấm Start trên giao diện → Orchestrator thức dậy → Bot bắt đầu đăng bài → Log hiện trên Dashboard.

## Implementation Steps
1. [ ] Mở web, vào Admin → Tab "Vận Hành"
2. [ ] Bấm Start, chờ 30 giây xem Bot có tự hoạt động không
3. [ ] Kiểm tra Activity Log có cập nhật thông tin mới
4. [ ] Bấm Stop, xác nhận Bot ngừng hoạt động
5. [ ] Dọn dẹp code, xóa file test tạm

## Test Criteria
- [ ] Orchestrator start/stop hoạt động đúng từ giao diện
- [ ] UI phản hồi nhanh, không lag
- [ ] Log hoạt động chính xác
