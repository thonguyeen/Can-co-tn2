# Changelog

All notable changes to this project will be documented in this file.

## [2026-04-14]

### Added
- **Admin RBAC System (Phases 01-04):**
  - Added `role` column to `User` model (USER, MODERATOR, ADMIN).
  - Integrated `role` into NextAuth JWT and Session properties.
  - Implemented client-side `SessionProvider` in root layout for widespread access to user role.
  - Added helper script `scripts/set-admin-role.ts` to assign exact admin roles safely.

### Changed
- **Security & Authorization:**
  - Upgraded Next.js `middleware.ts` to include a 3-tier routing guard blocking `/admin` pages based on roles.
  - Refactored `requireAdmin` logic into a generic session-based `requireRole()` helper in `lib/admin/guard.ts`.
  - Upgraded `/api/bots` and `/api/orchestrator` routes to require the `ADMIN` role for mutating configurations and states.
- **Admin UI:**
  - `AdminLayout` and `AdminHubPage` now conditionally hide the "Bot Management" menu item and cards for `MODERATOR` users, displaying only what the role permits.

## [2026-04-13]

### Added
- **Global Chatbot (Phase 06):** 
  - Integrated `NHA.AI` assistant across all pages using `GlobalChatbot` FAB.
  - Implemented persistent chat history backed by Prisma `AIChatMessage` model.
  - Added Market Context Injection: Chatbot extracts real market stats generated by the Analyst Bot.
  - Rate limiting (50 messages/day) applied for registered users.
- **n8n Crawler Infrastructure (Phase 06b):**
  - Added `n8n` into `docker-compose.yml` for SPA/headless browser scraping.
  - Implemented `/api/crawler/webhook` to ingest incoming n8n data. Includes constant-time auth, Zod-like structural validation, and automated deduplication against `saveRawNewsFromCrawl`.
- **Analyst Bot (Phase 05):**
  - Added automated daily market report generation relying purely on Prisma aggregations (`_avg`, `_count`) to ensure factual accuracy over AI hallucinations.
- **Integration Testing (Phase 07):**
  - E2E testing test suite implemented in `scripts/test-bot-revamp.ts`, successfully passing 14 integration points across crawler pipelines, content curation, intent extraction, scheduling, and chat context.

### Changed
- Re-architected Chat API `POST /api/chat` to include authentication and fallback safety nets.
- Enhanced `useChat` hook to correctly manage the asynchronous fetching of history upon initialization while resolving stale React closures via `useRef`.

### Fixed
- Fixed relative import scope issues inside the tsx test scripts `test-analyst-bot.ts` and `test-phase-06b.ts`.
